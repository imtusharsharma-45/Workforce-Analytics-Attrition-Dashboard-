# HR Analytics Dashboard Project

## Project Objective
The objective of this project is to analyze employee attrition data and identify factors affecting employee retention, satisfaction, and performance.

---

## Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- VS Code

---

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Business Insights Generation
5. Power BI Dashboard Creation

---

## Key Insights
- Employees with overtime show higher attrition
- Lower salary employees are more likely to leave
- Sales & R&D departments have higher attrition
- Job satisfaction impacts employee retention
- Younger employees show relatively higher attrition

---

## Dashboard Features
- Attrition Rate KPI
- Department-wise Attrition
- Overtime Analysis
- Gender Analysis
- Age Group Analysis
- Interactive Filters
